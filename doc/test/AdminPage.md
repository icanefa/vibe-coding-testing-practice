# AdminPage 測試案例清單

> 狀態：初始為 [ ]、完成為 [x]
> 注意：狀態只能在測試通過後由流程更新。

---

## [x] 【前端元素】初始畫面渲染
**範例輸入**：載入 AdminPage 頁面 (假設身分為 admin)  
**期待輸出**：正確渲染頁面標題「🛠️ 管理後台」、返回連結、登出按鈕以及「管理員專屬頁面」資訊卡片

---

## [x] 【前端元素】依據使用者角色顯示 Badge (管理員)
**範例輸入**：使用 `user: { role: 'admin' }` 載入頁面  
**期待輸出**：畫面上的 role-badge 區域應顯示「管理員」

---

## [x] 【前端元素】依據使用者角色顯示 Badge (一般用戶)
**範例輸入**：使用 `user: { role: 'user' }` 載入頁面  
**期待輸出**：畫面上的 role-badge 區域應顯示「一般用戶」

---

## [x] 【邏輯流程】點擊返回按鈕時導航至 Dashboard
**範例輸入**：點擊「← 返回」連結  
**期待輸出**：元件應透過 `Link` 導航至 `/dashboard`

---

## [ ] 【邏輯流程】點擊登出按鈕時呼叫 logout 並導航至 Login
**範例輸入**：點擊「登出」按鈕  
**期待輸出**：應呼叫 AuthContext 提供的 `logout()` 函式，並使用 `navigate` 導航至 `/login`，帶有 `{ replace: true, state: null }` 參數
